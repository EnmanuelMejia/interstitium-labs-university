## DevOps SuperLab

- **Purpose:** A portfolio lab (explicitly *not* paid production) built to walk hiring managers through a live DevOps stack in interviews. Repository: github.com/EnmanuelMejia/devops-superlab. Public hub page: interstitiumlabs.dev/labs/superlab/.
- **Stack:** Kubernetes (kind for local), Kustomize (dev/stage/prod overlays), Helm (incl. OCI release workflow), Argo CD (GitOps, app-of-apps pattern), GitHub Actions (CI, security, docs, Helm OCI release), Docker/Buildx with GHCR, Gatekeeper (policy constraints), Conftest (Rego policy-as-code), Prometheus/Grafana + Loki/Promtail + Tempo + OpenTelemetry (observability docs), Terraform (IaC practices in the lab narrative), pre-commit, Renovate, MkDocs (Material) docs site.
- **Key components:**
  - `make kind-up` — bootstraps a local kind cluster with ingress, metrics, monitoring, logging.
  - `make kustomize-dev|stage|prod` — Kustomize overlay apply flows (dev overlay script is fish shell).
  - `gitops/argocd/` — Argo CD install manifests + app-of-apps root app targeting the dev overlay.
  - `policies/` — Gatekeeper constraint requiring CPU/memory requests & limits; Conftest Rego rule requiring container images from `ghcr.io/`.
  - `.github/workflows/` — ci.yml (build/test, kubeconform validation of overlays, Syft SBOM), security.yml (Trivy fs/config/image, Checkov for IaC), docs.yml (MkDocs → GitHub Pages), helm-oci-release.yml.
  - `scripts/` — kind bootstrap, image build/push (buildx → GHCR), test runner, self-test (fish; assumes some host-local helpers — treat as optional).
- **What it demonstrates:** Local-to-GitOps workflow, policy gates before deploy, supply-chain hygiene (SBOMs, image scanning, signed provenance via GHCR), docs-as-code. Honest scope is stated in the README: portfolio/interview demo, not employer production.
- **Uncertainty:** Some scripts reference host-local helpers (e.g., `~/devops-status.fish`); the portable path is the documented `make` targets and `docs/`.

## LPS Enrollment Analysis

- **What it analyzes:** Lawrence Public Schools (LPS) district enrollment trends, 2019–2024, for an HR Information Systems & Data Analyst interview (prepared April 2025; the role was not started due to a family emergency — a portfolio work product, not a placement claim).
- **Method:** Python/matplotlib (`analysis.py`) charting Massachusetts DESE public enrollment profile data; 20-slide stakeholder deck (`LPS_Enrollment_Analysis_Enmanuel_Mejia.pptx`).
- **Headline findings (from the deck's data tables, which are the record):** Enrollment declined ~3.16% over five years (13,748 in 2019 → 13,313 in 2024, −435 students), tracking the statewide decline; 94.6% Hispanic/Latino enrollment vs. 25.9% state average; 48.1% of kindergarteners are English learners (~85% of ELL students speak Spanish at home); 86.9% of kindergarteners low-income (Title I implications); students with disabilities 61.2% of Pre-K, 20.0% of kindergarten.
- **Recommendations delivered:** HR — prioritize bilingual kindergarten teachers, counselors, autism specialists; DEIB — expand bilingual programs (e.g., UNIDOS), culturally responsive teaching; Technology — real-time enrollment dashboard shared by schools, HR, and planning.
- **Caveats (from the README):** Some deck speaker notes contain AI-drafted claims contradicting the data tables (e.g., an "8% growth since 2018" narrative vs. the measured 3.16% decline) — the tables are the record. One 2024–25 early-grade chart was labeled hypothetical (DESE had not published that year in-session). Always re-pull current DESE figures before presenting externally.
- **Outputs:** the .pptx deck + runnable `analysis.py` (gender-by-grade distribution chart, 2019–2020).
